v1.1.5

- Fixed Disable Break Cooldown not working properly
- Added Anti-Spleef
    - /sbc config set anti-spleef [true/false]
    - Prevents you from mining blocks under you unless mining straight down

- Added Powder Chests
    - Changes the hitboxes of powder chests to 1x1x1, and disables the interaction box when opened
        - /sbc config set powder-hitboxes [true/false]
    - Automatically drill swaps to first +powder in hotbar and opens powder chests
        - /sbc config set auto-open-powder [true/false]

- Added Glass Pane Fix
    - Fixes glass panes to sync with the server like 1.8
        - /sbc config set pane-fix [true/false]

- Beach ball patches
    - Added hotbar support when launching a new ball
    - Allowed precision snapping when close
        - /sbc config set beachball-snap [true/false]

- Added Fusion Helper
    - Repeats previous fusion in Fusion Machine (Togglable)
        - /sbc config set fusion-helper [true/false]

- Added Lasso features
    - Blocks invalid reels
        - /sbc config set lasso-blockreel [true/false]
    - Auto-reel when ready
        - /sbc config set lasso-autoreel [true/false]

- Added Fishing Macro
    - Automatically reels and recasts the rod, best used for trophy fishing because Hypixel has anti-macro for sea creatures
        - /sbc config set fishing-macro [true/false]
